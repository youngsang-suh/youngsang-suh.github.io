English

“rclone (personal)” (“the app”) is a personal tool used to download the operator’s own Google Drive files with read-only access.

  • Information collected: The app accesses only files in the operator’s own Google account. It does not collect data from any other user.
  • Storage: Downloaded data is stored only on the operator’s personal computer.
  • Sharing: Downloaded data is not shared with or sold to any third party.
  • Google API data: The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
